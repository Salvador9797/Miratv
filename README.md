# Mira

Mira es una aplicación Android nativa para descubrir y reproducir películas, series cortas y documentales mediante fuentes autorizadas.

## Descargas

Las versiones oficiales se publicarán en [Releases](https://github.com/Salvador9797/Miratv/releases). **La APK 0.3.1 ya está firmada y verificada, pero todavía no se ha adjuntado a un Release público.** La APK de esta conversación está disponible para pruebas de instalación.

No instales artefactos QA ni APK sin firmar como si fueran versiones oficiales.

## Estado de la versión

La versión preparada es **0.3.1** (Android, paquete de producción `app.mira.movies`, versionCode 4).

- Compilación, pruebas unitarias y validación de 15 endpoints: correctas.
- Prueba de reproducción Media3 en emulador Android: correcta.
- APK de producción: alineada y firmada con Android APK Signature Scheme v2 y v3; certificado y metadatos verificados.
- Prueba de instalación en dispositivo Android físico: pendiente.
- Publicación de la APK en GitHub Releases: pendiente.

Consulta el [historial de cambios](CHANGELOG.md) y el [estado de publicación y las verificaciones](RELEASE_STATUS.md).

## Código fuente

El código fuente de desarrollo se mantiene en un repositorio privado. Este repositorio público se utiliza para distribuir versiones oficiales compiladas y documentación para usuarios.

## Contenido y disponibilidad

La disponibilidad de títulos depende de las licencias, la región y las condiciones de cada proveedor. Mira prioriza fuentes abiertas o con autorización verificable y no elude DRM ni controles de acceso.
