# Mira

Mira es una aplicación Android nativa para descubrir y reproducir películas, series y documentales mediante fuentes autorizadas.

## Descargas

Las versiones públicas y sus notas se publicarán en [Releases](https://github.com/Salvador9797/Miratv/releases).

## Privacidad y seguridad

- [Política de privacidad](PRIVACY.md)
- [Política de seguridad](SECURITY.md)

## Código fuente

El código fuente de desarrollo se mantiene en un repositorio privado. Este repositorio público se utiliza para distribuir versiones compiladas y documentación para usuarios.

## Estado

Mira está en desarrollo. Las compilaciones de prueba no deben considerarse versiones estables. La disponibilidad de títulos depende de las licencias, la región y las condiciones de cada proveedor.
