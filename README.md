# Mira

Mira es una aplicación Android nativa para descubrir y reproducir películas, series cortas y documentales mediante fuentes autorizadas.

## Descargas

Las versiones oficiales se publicarán en [Releases](https://github.com/Salvador9797/Miratv/releases). **Todavía no hay una APK de producción publicada.** No instales artefactos QA ni APK sin firmar como si fueran versiones oficiales.

## Estado de la versión

La versión de desarrollo actual es **0.3.1** (Android, paquete de producción `app.mira.movies`, versionCode 4).

- Compilación y pruebas unitarias: correctas.
- Comprobación de los 15 endpoints del catálogo: correcta.
- Prueba de reproducción Media3 en emulador Android: correcta.
- APK QA: generada por CI, solo para pruebas.
- APK de producción: compilada sin firmar por CI; pendiente de firma local con el certificado permanente y prueba de instalación en dispositivo físico.

Consulta el [historial de cambios](CHANGELOG.md) y el [estado de publicación y las verificaciones](RELEASE_STATUS.md).

## Código fuente

El código fuente de desarrollo se mantiene en un repositorio privado. Este repositorio público se utiliza para distribuir versiones oficiales compiladas y documentación para usuarios.

## Contenido y disponibilidad

La disponibilidad de títulos depende de las licencias, la región y las condiciones de cada proveedor. Mira prioriza fuentes abiertas o con autorización verificable y no elude DRM ni controles de acceso.
