# Historial de cambios

## 0.3.1 — preparación de primera distribución

### Añadido
- Catálogo curado de películas abiertas de Blender Foundation / Blender Studio.
- Colección de cortos Caminandes.
- Ficha documental con enlace a la página oficial de The Indie Film Network.
- Búsqueda por título, sinopsis y fuente; filtros por tipo de contenido.
- Favoritos guardados localmente.
- Fichas con sinopsis, año, duración, fuente, licencia y atribución.
- Registro modular de proveedores y conector para el catálogo abierto de Blender.
- Reproducción integrada mediante Media3 para enlaces directos MP4/WebM autorizados.
- Apertura de la página oficial cuando no existe un enlace directo reproducible.

### Verificación
- Pruebas unitarias y validación de endpoints completadas en GitHub Actions.
- Prueba instrumental de reproducción Media3 completada en emulador Android.
- La APK de producción debe firmarse con la clave permanente y probarse en un dispositivo físico antes de publicarse.

### Notas
- Esta versión no ofrece un catálogo comercial completo.
- La disponibilidad depende de las licencias y de cada fuente.
- No se incluyen mecanismos para eludir DRM, paywalls ni controles de acceso.
- La versión 0.3.1 todavía no está publicada como APK oficial.
